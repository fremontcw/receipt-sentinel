## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Overclaiming in docs or narration | A Codex review found README/video claims the code didn't back (schema "forced", "can't" be injected, "nothing saved", "every PR", deterministic output) | blocking | Check every claim in README, `docs/walkthrough.md`, the hosted page and narration against the code path before writing it |
| Spending on the API key unasked | A real eval run costs about $0.29; a PR touching scoring/prompts/golden triggers another in CI | advisory | Say the cost (local run + the CI run) and ask before any real-model run |
| Azure applies via auto mode | The classifier blocks Azure deploys and security-weakening changes (filter edits) | advisory | Hand the author a short `!` command; never route around the block |
| Live demo cold start | Container Apps scales to zero; the first page load can take ~25 s and break a 30 s browser timeout | advisory | `curl` the demo once before recording or testing against it |
| `printf` with `%` in PR bodies | A `94.1%` in a printf format string aborted the PR command | advisory | Write PR bodies with a quoted heredoc and `--body-file` |
