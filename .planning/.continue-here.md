## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Trusting macOS for Linux container behavior | macOS Podman file sharing shows every file as the host user, so a uid bug that breaks Linux passed locally | advisory | CI runs `scripts/container_smoke_test.sh` on both docker and podman; reproduce uid issues with `podman machine ssh` |
| Per-arch image digests | `podman image inspect --format '{{.Digest}}'` returns the arm64 manifest, not the multi-arch list | advisory | Pin the RepoDigest whose `podman manifest inspect` lists several platforms |
| `cmd \| grep -q` under `set -o pipefail` | grep exits early and `make` dies with SIGPIPE (141) | advisory | Capture output in a variable, then `grep -q <<<"$output"` |
| Piping checks through `tail` | `mypy \| tail` hides mypy's failure exit code | advisory | Run checks unpiped, chained with `&&` |
| Spending on the API key unasked | CI evals and local real runs cost about $0.22 each | advisory | Say the cost and ask before any real-model run |
