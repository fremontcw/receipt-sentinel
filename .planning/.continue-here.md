## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Trusting "lint clean" claims | One implementer reported ruff clean when it was not (E501). | advisory | Controller re-runs `uv run ruff check .` and `uv run mypy` on every task head before review; reviewers paste real output. |
| Plan text vs. live SDK/model | Plan mandated `temperature=0`; SDK 1.2.0 has no such param and claude-sonnet-5 rejects it. Same model has adaptive thinking on by default → would truncate JSON at max_tokens=1024. | advisory | Load the `claude-api` skill before touching `anthropic_llm_client.py`; never take model params from memory. |
| One fake baseline for two jobs | A fake baseline cannot both keep CI green and demonstrate a regression. | advisory | `--fake` = clean oracle; `--demo-noise` for the demo. Keep them separate. |
